# Changelogs

The project's timeline: what landed, when. Files archive under `YYYY-MM/` (e.g. `2026-09/`); the month is only for time navigation — no deeper feature subdirectories.

## How to find things

- **What happened recently**: open the newest month.
- **A specific feature**: search `book/README.md` for the feature name or a keyword.
- **Full context**: follow the same date into `notes/summary/`, `notes/learn/`, and `notes/issue/`.

## Naming

`YYYY-MM-DD-<version-or-description>.md`
